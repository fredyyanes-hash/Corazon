# Corazón Cocina Mexicana

Website for Corazón Cocina Mexicana, a family-owned Mexican restaurant at 6800 Visitors Cir, Orlando, FL.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to view it.

- `index.html`: home page
- `lunch-menu.html`, `dinner-menu.html`, `bar-menu.html`: menu pages
- `css/site.css`: all styles
- `js/site.js`: header, menus, menu-page tabs, job application dialog
- `img/`: logos and banner photos
